# OldArcade

Portal de jogos clássicos, construído jogo a jogo com HTML indexável, conteúdo editorial verificado e experiência de jogabilidade em primeiro lugar.

## Fluxo

- `main`: base estável; publicação somente após aprovação do proprietário.
- `feat/fundacao-snake`: primeira entrega de desenvolvimento.
- Sem Lovable e sem deploy automático.
- Nunca apresentar contagens locais como globais.
- Ranking global e administração exigem backend autenticado e validação de pontuação.

Consulte `docs/ARQUITETURA.md` na branch de desenvolvimento.
